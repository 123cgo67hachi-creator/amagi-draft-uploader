Privacy Policy

  1. The only data this tool receives from TikTok is the access token and basic profile information (open ID, display name) of the owner's own account, used solely to upload drafts.
  2. This data is stored only on the owner's local computer. It is not sent to any other server and is never shared with or sold to third parties.
  3. No data from other TikTok users is collected.
  4. Access can be revoked at any time from the TikTok app settings (Security > Manage app permissions).
